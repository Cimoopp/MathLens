# MathLens 🔍➗

Офлайн-решатель школьной математики для Android: навёл камеру на пример → программа сама
распознала цифры и знаки → показала ответ и **пошаговое решение**.

Всё работает без интернета: своя нейросеть распознаёт символы прямо на телефоне,
а считает SymPy — поэтому ответ всегда точный (дроби, степени, корни, логарифмы).

## Что умеет

- 📷 Снимок примера камерой или фото из галереи
- 🧠 Своя свёрточная сеть (CNN) на 21 класс: `0-9 + - * / = . ^ ( ) x y √`
- 🧮 Решение через SymPy: арифметика, дроби, проценты, степени, корни, логарифмы, уравнения
- 📝 Пошаговый разбор: перенос членов, приведение к виду, деление на коэффициент, проверка подстановкой
- 🕘 История решённых примеров (сохраняется в памяти телефона)
- ✍️ Ручной ввод примера с клавиатуры — на случай непонятного почерка

## Структура

```
main.py                     экран приложения (Kivy): камера, результат, история
mathlens/vision.py          обработка снимка и нарезка на символы (Pillow + numpy)
mathlens/recognizer.py      инференс своей CNN на numpy (без TensorFlow!)
mathlens/solver.py          решение и пошаговый разбор (SymPy)
mathlens/history.py         история решений (JSON)
models/symbols.npz          веса обученной модели
train/train_symbols.py      обучение модели (Keras) → экспорт весов в npz
buildozer.spec              сборка APK
.github/workflows/apk.yml   автосборка APK в облаке → Releases (тег apk-latest)
```

## Сборка APK

Локально:

```bash
pip install buildozer cython
buildozer -v android debug        # APK появится в bin/
```

В облаке: просто сделай push в `main` — workflow соберёт APK и положит его
в раздел **Releases** с тегом `apk-latest` (как в твоих других проектах).
Сборка идёт долго: первый раз 40–60 минут, дальше быстрее за счёт кеша.

## Сколько занимает памяти (офлайн-вариант)

| Компонент | Размер |
|:---|---:|
| Kivy + Python-рантайм в APK | ~40 МБ |
| SymPy + mpmath | ~20 МБ |
| numpy + Pillow | ~20 МБ |
| Своя модель (веса npz) | 1–3 МБ |
| **APK** | **80–110 МБ** |
| Занято на диске после установки | 150–220 МБ |
| ОЗУ во время работы | 150–300 МБ |

Считаем: 40 + 20 + 20 + 3 = **83 МБ** — это нижняя граница APK.

## Обучение своей модели

```bash
pip install tensorflow numpy pillow
python train/train_symbols.py --data data/symbols --epochs 30
```

`data/symbols/` — папки по классам (`0`, `1`, …, `plus`, `minus`, `x`, `sqrt` …).
Скрипт обучает ту же архитектуру, что работает в приложении, и сохраняет
`models/symbols.npz` — обычный numpy-архив, который читается на телефоне без TensorFlow.

## Ограничения (честно)

- Камера хорошо берёт печатные и аккуратные рукописные **короткие** примеры в одну строку.
- Длинные функции (`log`, `sin`, `cos`) удобнее вводить с клавиатуры — они собираются
  из нескольких букв, и посимвольное распознавание тут ошибается. Введённые вручную
  они решаются полноценно.
- Дроби «в столбик» (числитель над знаменателем) пока читаются как деление через `/`.
